# YJJWacky 개발 일지

영상 내레이션·자막 소스. 원본 미디어는 `DevLog/Footage/` (git 제외).

## 2026-11-16 프로젝트 시작: 흐느적 디펜스

- 출발점: 휴먼 폴 플랫, 고트 시뮬레이터, TABS의 공통점은 "흐느적거리는 물리가 웃긴 장면을 만들고, 플레이어가 그걸 스스로 퍼뜨린다"는 것.
  이걸 타워 디펜스에 섞는다. 흐느적거리며 몰려오는 적을 흐느적거리게 막는다.
- 캐릭터에 애니메이션이 하나도 없다. 몸통·머리·팔·다리 여섯 덩어리를 관절로 이은 래그돌이고,
  몸통을 띄우는 스프링 + 바로 세우는 토크 + 다리 흔드는 토크만으로 걷는다. 일부러 무르게 잡아서 비틀거린다.
- 죽이는 방법이 체력 깎기가 아니라 "길 밖으로 날리기". 길에 난간이 없어서 물에 빠지면 끝.
- 타워 4종: 펀치(권투 장갑), 대포(진짜 물리 포탄), 선풍기(바람), 몽둥이 병사(아군 흐느적이).
- 그래픽: TABS 참고. 텍스처 없는 단색, 각진 로우폴리 땅, 빨강 대 파랑, 왕눈이 눈.
- 지켜야 하는 건 푸딩. 뜯기면 출렁인다.
- 한꺼번에 다섯 이상 쓰러지면 "떼죽음" 슬로 모션.

## 2026-11-17 다듬기

- 캐릭터가 화면에서 작아 보여서 맵을 70%로 줄이고 흐느적이를 1.2배로 키웠다.
- 그랬더니 타워도 없는데 적이 스폰되자마자 수십 미터 뒤로 날아가 물에 빠지는 버그.
  계측해 보니 나이 0.04초, 옆 놈과 거리 11cm, 높이 23cm(땅속). 스폰 자리 고르기가 8번 다 실패하면
  기본값(땅 높이 0)에 꽂혀서, 땅·서로에게 파묻힌 몸이 첫 물리 프레임에 폭발하듯 튕겨 나간 것.
  고친 뒤로는 자리가 없으면 머리 위에서 떨어뜨린다 (부하 테스트에서 60마리가 쌓여 쏟아지는 장면 = 영상 소재).
- 서 있는 놈끼리 부딪혀서는 다치지 않고, 날아온 놈에게 치이면 나동그라지기만 한다 (도미노).
- 펀치 타워를 깜짝 상자 모양으로 (뒤로 젖혀진 노란 뚜껑 + 용수철 + 권투 장갑).

## 2026-11-17 무게·강화·새총

- 레벨 디자인의 중심을 "무게"로. 꼬마 15kg ~ 대장 500kg. 날아가는 거리는 무게에 반비례.
  웨이브는 총 무게 예산(480kg -> 5,000kg)을 몬스터별로 나눠 짠다. HUD에 총 무게, 뚱보·대장 머리 위엔 몸무게 표.
- 타워 강화 Lv1~3: 펀치 연타, 대포 세 발, 선풍기 회오리, 몽둥이 징.
- 새총 타워: 무게 한도 안의 놈을 올가미로 낚아채 고무줄을 당겼다가 앞선 무리에 볼링공처럼 쏜다 ("덥석!", "슝!", "스트라이크!").
  표적이 없으면 뒤쪽 물에 던져 버린다 ("저리 가!"). Lv3은 뚱보도 집는다.
- 펀치에 맞은 놈이 공중에서 관절이 휘둘리는 걸 "충돌"로 세어 공중에서 죽던 문제 -> 땅 근처에서만 충돌 피해. 풍덩 비율 0% -> 96%.

## 2026-11-21 중세 판타지 리소스 재편 + 걷기 물리 수정

- 엔진 기본 매끈한 도형 대신 각진 로우폴리 도형(공·팔각기둥·반구·삼각기둥·사다리꼴·고리)을 런타임에 구워 TABS 느낌.
- 몹: 농민병(밀짚모자·쇠스랑), 도적(두건·복면·보따리), 뚱보 기사(쇠 배·콧수염·방패·철퇴), 왕(왕관·흰 수염·망토·홀), 고블린(냄비 투구·긴 코·뼈다귀), 아군 경비병.
- 타워: 철주먹 상자, 청동 대포, 풍차, 경비병 막사, 거대 새총. 맵: 푸딩 성, 적 진영 문, 섬 오두막·풍차·성채.
- 사진: `RunGame.ps1 -Mode play -Tests gallery` → `Saved/Screenshots/Play_G*.png` (HUD 없는 사진 모드).
- 걷기 "와리가리" 원인: 몸 돌리는 힘에 감쇠가 없었고, 자세 목표를 일부러 좌우로 흔들었고, 걸음 박자가 시간 기준(서 있어도 다리 휘적), 스프링이 다 감쇠 부족.
  - 고친 뒤 걷는 몸통 평균 회전: 좌우 돌기 9.67 → 0.25 rad/s, 기울기 2.72 → 0.13 rad/s. 팔은 축 늘어져 다리 반대로 흔들림.

## 2026-11-21 (2) 걷기 "발발발" 떨림의 진짜 원인
- 흐느적 버전은 너무 늘어져서 예전 자세(좀비 팔, 단단한 몸통)로 되돌리고 떨림만 잡았다.
- 범인: 팔. 어깨가 170도까지 들려서, 팔이 거의 수직으로 서면 관절 계산이 특이점에 걸려 팔이 초당 200~370 rad 로 떨고 몸통까지 흔들었다.
  어깨 한계 170 -> 130도로 끝. (부위별 회전 속도를 로그로 찍어서 찾음)
- 그 밖에: 몸 돌리는 힘 감쇠, 걸음 박자는 걸은 거리로 + 상한(빠른 도적은 보폭을 넓힘), 몸통·머리는 미끄럽게(무리끼리 비비며 돌지 않게).
- 걷는 몸통 평균 좌우 회전 9.67 -> 0.2 rad/s. 테스트는 소리 끔(-nosound, Audio.Master 0).
